# Notes

This is mainly just a collection my persnoal notes as well as some useful resources I have come across on the internet.

- [CD Ripping Terminology](https://docs.linn.co.uk/wiki/index.php/CD_Ripping_Terminology). Information about the different kinds of jitter (EFM, Sampling, and Read Offset) and error correction.
- [CD-R FAQ](https://www.cdrfaq.org/faq02.html). General information regarding CD-R
- T10 Standards. Available through the Internet Archive. Go to: <https://web.archive.org/cdx/search/cdx?url=www.t10.org/ftp/t10/drafts/*&output=json>tput=json> to see what is available.
- [SCSI Standards Architecture](https://www.t10.org/scsi-3.htm)
